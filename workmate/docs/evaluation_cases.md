# WorkMate AI 效果评估记录

## 评估原则

- 规则问答只依据知识库资料回答，并展示来源。
- 知识库没有依据时，明确说明无法确认，不编造规则。
- 运营分析仅依据 MCP 商家数据工具返回的数据生成建议。
- 工具失败时，说明失败原因，不把失败当作空数据或成功结果。
- 商家内部指标不得出现在面向买家的规则答复中。
